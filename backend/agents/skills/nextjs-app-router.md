# Next.js 16 App Router (verified against the bundled docs, next 16.4.1)

This is the summary AGENTS.md wants you to get from node_modules/next/dist/docs. Open a
docs page only if this doesn't answer your question; name the exact file, don't browse.

## Files
- A route is a folder under `src/app/` with a `page.tsx` that default-exports a component:
  `src/app/about/page.tsx` → `/about`.
- `src/app/layout.tsx` is the root layout: it wraps every page. Anything every page
  shows (header, footer) goes here, once.
- Shared components: put them in `src/components/` unless the repo already has a
  pattern; import with the `@/` alias (tsconfig maps `@/*` to `src/*`).
- Other route files when needed: `loading.tsx`, `error.tsx`, `not-found.tsx`.
  Docs: 01-app/01-getting-started/03-layouts-and-pages.md

## Server vs client components
- Components are Server Components by default: no `useState`, `useEffect`, event
  handlers or browser APIs.
- Anything with state or handlers (a counter, a form with onChange) needs `"use client"`
  as the first line of its file. Keep it small: make the interactive part its own
  client component and render it from the server page.
  Docs: 01-app/01-getting-started/05-server-and-client-components.md

## Links
- Internal links use `import Link from "next/link"` and `<Link href="/about">About</Link>`.
- Plain `<a>` only for external URLs.
  Docs: 01-app/01-getting-started/04-linking-and-navigating.md

## Metadata
- Static: `export const metadata: Metadata = { title: "About" }` from the page or layout,
  with `import type { Metadata } from "next"`.
  Docs: 01-app/01-getting-started/14-metadata-and-og-images.md

## Typed props (new in 16)
- `PageProps<'/route'>` and `LayoutProps<'/route'>` are global helpers (no import),
  generated by `next typegen` (the repo's `typecheck` script runs it first).
- `params` is a Promise: `const { slug } = await props.params` in an async page.
- A page with no params can take no props at all.
